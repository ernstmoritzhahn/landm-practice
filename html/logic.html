        Notation. Unicode or ASCII; ASCII is normalised as you type:
        ~ ! → ¬ 
        && & /\ → ∧ 
        || | \/ → ∨ 
        -> => → → 
        <- <= → ← 
        <-> <=> == → ↔ 
        also ⊕ xor, ↑ nand, ↓ nor.

        Quantifiers: ∀x. / \forall x., ∃x. / \exists x.
        (several variables: ∀x,y. or ∀x y.;
        a quantifier's scope is the smallest following formula —
        ∀x.p ∧ q reads as (∀x.p) ∧ q, write
        ∀x.(p ∧ q) for the wider scope).
        Constants ⊤ \top, ⊥ \bot.
        LaTeX commands work too: \forall \exists \neg \wedge \lor \ra
        \to \la \lra \oplus \up \down \top \bot — the input field
        normalises them (and the longer spellings \rightarrow,
        \uparrow, …) as you type; the intuitive
        pseudo-commands \not \and \or \true \false work as well.
        Predicate atoms p(t1,…,tn), terms a (const),
        x (variable: initials u v w x y z or bound),
        f(t1,…,tn) (function). Precedence: ¬ > ∧ ↑ > ∨ ↓ > → ← > ↔ ⊕.
